# HTML, CSS & JavaScript Projects 🚀

A collection of frontend projects built while learning and strengthening my **HTML, CSS, and JavaScript** skills.

This repository includes UI designs, interactive JavaScript applications, landing pages, and small frontend projects — from beginner-friendly builds to projects focused on real-world layouts and interactions.

## 📂 Projects

| Project                         | Description                                                                                                            |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 🛒 **Amazon Clone**             | A frontend recreation of the Amazon shopping interface, focusing on product layouts, navigation, and responsive UI.    |
| 🧮 **Calculator**               | A simple interactive calculator built with JavaScript to handle basic arithmetic operations through a clean interface. |
| 📅 **Mini Calendar**            | A lightweight calendar interface that dynamically displays the current date and calendar information using JavaScript. |
| 📸 **Photography WebPage**      | A visually focused photography website layout designed to showcase images through a clean and immersive interface.     |
| 🔳 **QR Code Generator**        | A JavaScript-based tool that generates QR codes from user-provided text or links.                                      |
| 🎮 **Simon Says**               | A memory-based JavaScript game where players follow an increasing sequence of lights and sounds.                       |
| 🍔 **Swiggy**                   | A food-delivery inspired frontend project focused on recreating a modern restaurant and food-ordering interface.       |
| 🔊 **Text to Speech Convertor** | A browser-based text-to-speech application using the Web Speech API to convert written text into spoken audio.         |
| ❌ **Tic-Tac-Toe Game**          | A classic two-player Tic-Tac-Toe game built with JavaScript, including game-state and winning-condition logic.         |
| ✅ **To-do List**                | A simple task-management application for adding, completing, and managing daily tasks using JavaScript.                |
| ✈️ **Travel Landing Page**      | A modern travel-themed landing page focused on visual design, responsive layouts, and engaging frontend presentation.  |
| 🌤️ **Weather App**             | A weather application that displays weather information through a responsive interface and API-based data.             |
